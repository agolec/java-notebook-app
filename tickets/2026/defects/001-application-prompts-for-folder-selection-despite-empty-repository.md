## Delete Folder Prompt visible when no folders exist

## priority
- low


## environment
Development

## Pre-Conditions
Repository has no folders/directories

## steps to reproduce
- Execute the main program
    -    Actual Outcome: Should be on the main menu prompt
- Select option 4 to delete folders
- Expected Outcome: You should see "No Folders exist" text.
- Actual Outcome: You will see "no folders exist" and still be prompted to delete a folder


## actual results

User will be prompted to select a folder for deletion, although there are none

## expected results
User should not be prompted to delete a folder if no folders exist
