Folder Creation Command
======

Type - Feature
=====

Priority - high
====

Estimate - 5
===

Description
==

As a user of this program, I want to be able to create folders
with the same execution flow that existed when this program was 
menu driven, so that I can drive program flow through input freely.




Acceptance Criteria
==
Program must allow creation of folders, as was
done through the menu driven output.

- If folder does not exist, one should be created
- If folder already exists, the folder must not be created
- If user does not enter a title, the folder must not be created
