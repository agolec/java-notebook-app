Folder Creation Command
======

Type - Feature
=====

Priority - high
====

Estimate - 5
===

Description
==

As a user of this program, I want to be able to create folders
through commands on the console, so that I can
freely create them at any time, without
having to rely on the menu to drive
me to the part of the code that creates them.




Acceptance Criteria
==
Program must allow creation of folders, as was
done through the menu driven output.

The program must allow creation of folders when the
create folder command is used

- User must type "Create Folder <folder name>"
 in order to create a folder.


- If folder does not exist, one should be created
- If the folder is successfully created, 
display a message to the user about it's success.
- If folder already exists, the folder must not be created
- If the folder creation does not succeed, inform the user with a message.
- If user does not enter a title, the folder must not be created
- User entering an empty title should receive output
informing them to enter one.
