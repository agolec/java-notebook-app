Title: Delete Note Command
======

Type: Feature
=====

Priority: 1
====

Estimate: 3
===

Description
==
As a person managing notes, I want a way to delete them
by commands so that I can remove notes I do not want to keep anymore.

Acceptance Criteria
==
When a delete note command is entered, the user receives
feedback about it.
- if the note exists, the user is told it gets deleted.
- if the note does not exist, the user is notified
