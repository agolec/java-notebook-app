Nested Folder
======

Type: Feature
=====

Priority: High
====

Estimate: 3
===

Description
==
As a user of a notes app, I want a way to place a folder inside of another folder, so that
I can have a hierarchy built up of notes.

Ex: At the highest level, a folder about groceries exists, and within that folder,
another level folders exists, ex: produce, clothing, meat, seafood, pharmacy

If the user selects groceries > produce, another set of folders can be created and viewed, such as "fruit, vegetables"

Acceptance Criteria
==
A folder can contain other folders.
