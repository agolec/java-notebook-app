Title - Folder Opening Command
======

Type - Feature
=====

Priority - 1
====

Estimate - 3
===

Description
==
Provide a means through commands for a user
to open a specific folder inside the note repository
through the console command implementation

As a user of the folder application, I would like to be
able to open a specific folder through console commands
so that I can then operate on its notes.

Acceptance Criteria
==

User must be given the option to prompt to open a Folder
If a folder does not exist, the user is given output
    - output "note does not exist" or similar.
If folder exists, open it and allow user to view notes inside it.
