Title
======
Delete folders

Type
=====
Feature

Priority
====
High

Estimate
===
3

Description
==
As a person using this notes application, I would like to be able to delete
folders, so that I do not over-clutter the existing space as development continues.

Acceptance Criteria
==
- A menu option to delete folders.
- If a folder is entered that does not exist, the user is informed and no change occurs.
- If a folder is entered that does exist, the user is asked to confirm y/n.<br><br>
- Once a user makes the choice to navigate to the delete folders menu, that menu has a means to cancel when brought to the selection screen, in order to back out.
